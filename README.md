# Smart Campus Explorer

Create a modern Smart Campus Digital Twin web dashboard for a university building.
Include an interactive 3D building viewer where users can navigate between floors, rooms, corridors, labs, classrooms, and offices.
Allow movement inside the building similar to a simple game experience (walk, zoom, rotate, select rooms).
Show room information, occupancy, temperature, energy usage, and fire-risk status when a room is selected.
Include a GIS map panel showing the building location on campus.
Add a dashboard with KPIs, charts, alerts, and real-time sensor monitoring.
Use a clean professional UI, dark mode, responsive layout, sidebar navigation, and futuristic smart-campus styling.
Design as a clickable UI/UX prototype for a graduation project, not a full implementation
